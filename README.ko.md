# R QR Reader for Haiku OS

[English](README.md)

웹캠으로 QR 코드를 읽습니다. 코드를 카메라에 비추면, 웹 주소는 브라우저로 열지 물어보고 그 외의 내용은 화면에 보여주고 복사할 수 있습니다.

![창 레이아웃](screenshots/window.png)

*카메라 화면은 가렸습니다 — 그대로 두면 카메라가 향한 곳이 찍힙니다.*

## 요구 사항

Haiku (x86 또는 x86_64)와 UVC 웹캠. 크로스 컴파일러가 필요 없으니 실행할 기기에서 그대로 빌드하시면 됩니다.

## 설치

```sh
./install.sh
```

컴파일한 뒤 바이너리를 `~/config/non-packaged/apps/`에 넣고, **Deskbar → Applications** 메뉴와 **바탕화면** 양쪽에 링크를 만듭니다.

```sh
./install.sh --build-only   # 빌드만 하고 설치하지 않음
./install.sh --uninstall    # 제거
```

## 사용법

스캔은 계속 돌아갑니다. 시작·정지 버튼이 없습니다. 인식 결과는 **다른 코드**를 읽을 때까지 화면에 남습니다.

- **웹 주소** — 브라우저로 열지 묻는 대화상자가 뜹니다.
- **그 외 텍스트** — 내용을 보여줍니다.
- **복사** 버튼은 결과를 클립보드에 넣습니다.

기울어진 코드, 회전, 흐림, 어두운 배경, 거울상을 읽습니다. 지원 범위는 버전 1~10 (21×21 ~ 57×57), 오류정정 레벨 L/M/Q/H, 숫자·영숫자·바이트 모드입니다. 한자 모드, ECI, 구조적 연결, Micro QR은 구현하지 않았습니다.
